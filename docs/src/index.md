# vscode-basex (v0.2.x)
`vscode-basex` is a [vscode](https://en.wikipedia.org/wiki/Visual_Studio_Code) extension providing support for development using `BaseX`. 
[BaseX](https://basex.org) is a Java based XQuery processor. 

!!! warning Status
    This extension is "Work in progress". Errors and changes to be expected.
    
## Installation
`vscode-basex` is published on [vscode marketplace](https://marketplace.visualstudio.com/items?itemName=quodatum.vscode-basex) and [open-vsx](https://open-vsx.org/extension/quodatum/vscode-basex), alternatively it can be manually [installed](installation.md).
